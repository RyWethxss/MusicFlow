# MusicFlow Privacy Notice

Last updated: 2026-10-26

MusicFlow is an on-device Android media display. It does not require a MusicFlow account, a Spotify login, or an internet connection.

## Data used by the app

When you grant Android's Notification access, MusicFlow uses Android's active media sessions to display the current track title, artist, album, cover art, playback position, and player app name. It sends playback controls to that active session when you use them. The app does not read notification text or notification content.

MusicFlow does not transmit media session data, cover art, or usage information to WETHWORKS or another server. It does not include analytics or advertising code. Media details are held in app memory while the screen is open and are not saved by MusicFlow. The selected display mode is saved locally in Android app preferences.

## Android permission

Notification access is an Android special access that you enable in system Settings. Android describes this access broadly. MusicFlow uses it to discover active media sessions; it does not inspect notification contents. You can revoke access at any time in Android Settings. Playback details stop updating after access is revoked.

## Contact

This preview does not provide a dedicated support or privacy contact. For this open-source project, questions can be raised through its public GitHub repository.
